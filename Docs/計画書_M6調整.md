### 最重要: 裏道の問題
ゲームの核は「大通り(混雑で遅い)と裏道(速いが土地勘が必要)の選択」。推奨経路が裏道をほとんど使わない、または裏道の経験が0というのは、
- (a) 地図の数値で、裏道が常に不利になっている、または
- (b) 推奨経路の計算が、配達員の土地勘を考慮していない、または
- (c) 裏道がある区間が、目的地の経路に含まれていない、

のどれかの可能性がある。**この確認なしに、土地勘の訓練や素質の議論は意味を持たない。** 先に調べる(T-1)。

### T-1: 裏道の調査

**目的**: 「裏道が、土地勘の高い配達員にとっては速い」という設計が、実際の地図で成り立っているかを確かめる。

**調べること**
1. 地図のすべての配達先について、**土地勘が 0.3 / 0.6 / 0.9 の配達員**それぞれの、所要時間が最短の経路を求め、裏道を含むかどうかを一覧にする
2. 推奨経路(`RoadPathfinder`)が、配達員ごとの土地勘を使っているかを調べる(使っていなければ、使うべきかを判断として報告)
3. 裏道を使う意味が出る条件を満たしているか: 「大通りの混雑(`TrafficFactor`)× 距離」と「裏道の距離 × (1 + (1−土地勘) × 係数)」を比べ、**土地勘が高ければ裏道が勝つ、低ければ大通りが勝つ**区間が、地図にあるか
4. なければ、**地図のデータ(距離・混雑係数)の調整案**を示す。例: 一部の区間の大通りの混雑係数を下げる/裏道を短くする。**適用する前に、案を報告して止まる**(私が判断する)

**完了条件**: 配達先×土地勘の表がある。裏道が選ばれる条件が、地図に存在するかどうかが分かる。ない場合は調整案がある。

**指示文**
> 裏道の調査をお願いします。コードと数値は変更せず、調査と報告だけを行ってください。(1) 地図のすべての配達先について、土地勘 0.3 / 0.6 / 0.9 の配達員それぞれの最短所要時間の経路を求め、裏道を含むかどうかを一覧にしてください。(2) 推奨経路の計算(`RoadPathfinder`)が、配達員ごとの土地勘を考慮しているかを調べてください。(3) 土地勘が高ければ裏道が勝ち、低ければ大通りが勝つ区間が、地図に存在するかを確認してください。(4) 存在しない場合は、地図のデータ(距離・混雑係数)の調整案を、理由とともに示してください。地図のデータは変更しないでください。報告したら、そこで止まってください。
