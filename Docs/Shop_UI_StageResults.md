## 今回の修正

- 営業開始時のNullReferenceException：生成した区画タブをreadonly配列に格納していたため、スクリプト再読み込みで参照を保持できなかった。SerializeField付き配列に変更。指示盤の手順表示と店のタブも同じ保持方式へ変更。
- 区画タブの非表示をSetActiveからCanvasGroupへ変更。
- 新しい複数フォントとStickerButtonを既存の見た目検証へ接続。旧画面のチェックは維持し、新画面は指定されたフォントと最小16、各FontRoleと操作部品を確認する。
- クリック可能な通知とバッグ空き枠にStickerCardActionを追加。元のクリック処理と配置を保ち、ホバー/押下/無効表示を共有する。反応時間はUIThemeのInspector設定へ集約。
- 使用フォントと自作素材の出典をCreditsへ追記。素材再生成スクリプトの既定出力先を実際のResources/ShopArtへ修正。
