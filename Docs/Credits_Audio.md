# 音源のクレジット

すべてCC0（パブリックドメイン、クレジット表記は任意）。ファイルは `Assets/Resources/Audio/`。同じ名前のファイルに置き換えれば音を差し替えられる。

| ファイル | 使う場面 | 元の素材 |
|---|---|---|
| bgm_prep.mp3 | タイトル・開店準備・精算 | "Happy Clappy Loop" / owlishmedia（OpenGameArt） |
| bgm_business.ogg | 営業中 | "Flowerbed Fields [Loop]" / Zane Little Music（OpenGameArt） |
| bgm_story.mp3 | オープニング・エンディング | "Once Upon a Time (loop)" / tad（OpenGameArt） |
| ui_click | ボタン | Kenney Interface Sounds `click_002` |
| ui_toggle | （予備） | Kenney Interface Sounds `toggle_002` |
| order_new | 注文が入った | Kenney Interface Sounds `bong_001` |
| pick / drop | つかむ／置く | Kenney Interface Sounds `select_002` / `drop_002` |
| ticket | 伝票を作業台へ | Kenney Casino Audio `card-place-1` |
| ingredient | 生地・ソース・チーズ・具 | Kenney Impact Sounds `impactSoft_medium_001` |
| oven_in / oven_out | 窯に入れる／出す | Kenney RPG Audio `metalLatch` / `doorOpen_1` |
| bake_ready | 焼き上がりの帯に入った | Kenney Interface Sounds `glass_002` |
