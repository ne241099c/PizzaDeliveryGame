# S2-3 / S2-4 の追加実装

2026-10-23、shop。既存の調理状態・窯FIFO・自動梱包・名簿を再利用。ManualDeliveryRoute / RoadPathfinder は変更しない。添付資料の過去の段階・全検証指示は再実行せず、最新のユーザー方針に従い関連検証のみ。

## 操作

- 失敗したピザは保温棚に残り、横に原因と「このまま出す」「捨てて作り直す」が出る。未選択の間は自動梱包しない。保温棚は横スクロール。
- 焦げも違う具も配達可能。★1の品質ボーナスはなし。品質ボーナスを新仕様の★2 +15 / ★3 +40（期限内のみ）へ更新。旧シーンの8/20を引き継がない新しいSerializeField名を使う。
- 作業台のピザ、保温棚のピザ・箱を、作業台の左下の「ゴミ箱」ゾーンへドラッグして廃棄できる。対応中はゾーンが光る。右クリック / Esc で持つ操作を取り消せ、材料費はドロップ時だけ発生する。Escの取り消しではメニューを開かない。
- 廃棄は初期値20。配達袋・配達選択からも外れ、同じ伝票・期限で作り直す。空いた作業台があれば生地から再開。廃棄枚数・費用を精算に表示し、費用を二重に引かない。
- 生焼けでも窯から取り出せる。保温棚の「窯に戻す」、またはピザを窯へドロップ。焼いた秒数を保って窯FIFOへ戻り、残りを焼く。

## 内勤の引き継ぎ

- 最後の操作から初期値8秒。窯待ちから実際に焼き始めたときも猶予を更新する。操作・ソースをなぞる・ピザを持っている間に最終操作時刻を更新。
- **現在の作業は中断しない**。手が空いた内勤が、放置された窯のピザ / 生焼けを優先し、その後に放置された作業台の続きを行う。既に付いた品質の失敗は消さない。
- 失敗時に選択待ちのプレイヤーのピザは勝手に処分せず、プレイヤーが選ぶまで残す。「このまま出す」を選んだピザは内勤の作り直し対象外。
- 内勤の★1は、作り直して期限内に届けられる予測なら自動廃棄し、通常の待ち伝票より優先する。進行中の作業は中断しない。余裕がなければそのまま出す。★2は作り直さない。
- 自動作り直しの所要予測は本物の調理時間、窯・内勤の待ち時間、配達員の帰還待ちと最短の片道時間を利用。事故は予測に含めない。期限自体は変更しない。

## 初期マップ

新規ゲームの開始を3→5街区（届け先8→12）へ。以降は6日目8、11日目10、21日目12街区。街区の道路形状そのものは今回変更していない。以前の生成街は街バージョン1・途中版2として3/5/8/12を維持し、旧サンプル地図のセーブも維持。新規は街バージョン3。設定はMapManagerのCitySettings（Campaign Stage Blocks）。新しい段階設定には別のシリアライズ名を使い、Unity内に残る旧Inspector値を新規ゲームへ混ぜない。

## 判断した点

- 「今進んでいるタスクを最優先」は内勤が現在実行している工程を中断しない意味で実装。空いた後の窯の救出は、新しい伝票を取り始めるより優先する。忙しくて間に合わなければ焦げる可能性は残る。
- 放置時間は8秒を初期値とし、Inspectorで変更可能。選択待ちの失敗品はこの時間で自動承認しない。
- 自動取り出しは焦げさせない操作とし、焼きの品質点は他の工程同様に丁寧さで抽選する。以前の「内勤は必ず焼きの1点を得る」だと★1が発生せず、自動作り直しが働かないため更新した。乱数を固定した検証と確率0の境界条件で確認する。
- 空き作業台がないときは使用中のピザを押し出さず、作り直し伝票を優先待ちに残す。プレイヤーもその伝票を空いた台へ置ける。
- 廃棄時の材料費と、配達出発時の通常の材料費は別。一枚を廃棄して作り直して配達すると、その二枚分となる。
- 従業員の人数制限撤廃・自動梱包・受付猶予など、過去にユーザーが決めた仕様は維持する。収支の再調整や30日測定は今回行わない。
- 再読み込みで検証専用の代役が空の従業員として復元される不具合も修正。代役は非シリアライズで、空名の代役も除外する。

### 通常セーブの照合に関する未確定事項

各検証・撮影はPlay中の保存抑制で囲み、そのまま新規ゲーム→タイトルへ片付けた。撮影の開始前後では通常セーブ・最高記録のバイト一致を確認し、最後のPlayのコンソールエラーは0。

ただし、作業全体の開始時ハッシュと最終ファイルのハッシュは通常セーブだけが異なった。ファイル更新は11:28:14。こちらの操作記録は11:20:33で一旦止まり、ユーザーの「続きを」で再開するまで間がある。検証が更新したか、その間のUnity操作で更新されたかは未特定。ユーザーの返答は「覚えていません」。原因をこちらの上書きと断定した初報は訂正した。

現在のファイルは1日目・所持金300・街バージョン2の3街区で、これを勝手に変更していない。最高記録は作業開始時と一致。元の通常セーブのバイト列は保存しておらず、履歴・一時ファイル・ローカルスナップショットにも復元元を確認できなかったため、復元済み・全期間不変とは報告しない。

現行セーブと最高記録は `Library/ReviewBackups/20261023-123909/` にコピーして保全（git対象外）。通常保存を一時停止してPlayを終了した。今後は検証全体の開始前に、ハッシュだけでなく実ファイルをプロジェクトの非コミット領域へバックアップし、ユーザーが操作できる待機時間と検証時間を区別して比較する。
