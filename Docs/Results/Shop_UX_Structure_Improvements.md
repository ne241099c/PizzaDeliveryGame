# 配達・厨房・構成の改善（2026-10-23）

担当：Codex。shop、ローカルのみ、pushなし。既存のPrefab・シーン分割を維持して差分を変更した。

## 変更と操作方法

| 依頼 | 対応 |
|---|---|
| 従業員・配達員のスクロール | 空欄の入力面を追加。荷物のないカードのドラッグは一覧へ渡す。横一覧はホイールを下に回すと右へ進み、スクロールバーも使える。選択した配達員のレーンを表示範囲へ移す |
| 帰還ゲージ | 残り秒数に加えて、出発から帰還までの進捗を表示。事故で予定が延びるとゲージも更新 |
| 配達速度 | 共通倍率1.2→1.6。従来比約1.33倍。Inspectorで変更可能 |
| ピンの状態色 | 待ち＝黄、作り中＝青、焼き中＝赤、焼き上がり＝緑。色はUIThemeに集約 |
| 家・ピン | 新規は初期12→22軒（1街区4軒）。注文のない家は建物だけを残し、注文ピンを非表示 |
| 注文番号 | ピンの頭に大きな番号と白い背景。番号自体もクリック可能。地図は番号中心とし、名前は十分拡大したときに表示。宛先名は注文一覧・レーン・編集中の案内にも表示 |
| 裏道 | 大通りから離れた折れ線で表示。道路・選択判定・ルート線・配達員の移動でRoadGeometryを共用。計算用の距離は変更しない |
| ルート編集 | 「道を選ぶ」→通りたい道をクリック。同じボタンで次の区間、右クリックで終了。編集中の区間は黄色。従来の線ドラッグも維持。ピンを隠していた大きなつまみは撤去 |
| 積み荷・訪問順 | 荷物をクリックで降ろす。「順番を入替」で2件の訪問順を交換 |
| 注文カード | 品名・焼き上がり予測・配達期限を独立した行に分け、カード内に収める |
| 窯キュー | 待っているピザの絵・注文番号・品名をFIFO順に表示。多数時は横スクロール |
| 廃棄 | 廃棄費用0。廃棄枚数の記録と、元の期限は維持 |
| イカ | 4分割の1枚目を拡大していた画像設定をSingleへ修正。全体図を0.6倍で表示。UIThemeで変更可能 |
| 配達員の地図表示 | 拡大率にかかわらず44px以上を基準に表示 |

## 構成と安全性

- 26個の管理コンポーネントをGameManagerの4つの子（CoreSystems、CampaignSystems、KitchenSystems、DeliverySystems）に整理。185か所の参照を移し、欠落は0→0。
- BusinessViewの固定Prefabは必要部分だけをEditor APIで更新。再生成メニューは未保存シーンを保護し、既存Prefabをバックアップして上書きを確認する。
- 描画はPizzaVisual、道路の表示計算はRoadGeometry、一覧操作はScrollNavigationへ集約。ManualDeliveryRouteとRoadPathfinderは変更していない。
- セーブ読み込みに失敗した場合に、自動で新規ゲームとして元ファイルを上書きする経路を修正。元ファイルを保持し、タイトルで理由を表示する。
- 壊れた最高記録の金額でタイトルが停止しないよう検証する。
- 自動作り直しの配達予測にGameClockの時間換算を適用。期限の直前・直後を検証する。
- Tools/Reviewは実ファイルのバックアップ・前後比較を追加。後片付けでシーンを切り替えず、時計を止めて保存ロックを維持する。
- Test Runnerには厨房・生成街・セーブの短い既存検証を登録。長時間シミュレーションは追加していない。

## 判断した点

- 速度は倍率1.6とした。事故率・報酬・注文間隔などの追加調整は行わない。
- 既存v3の街も、元の全ノード・道路・距離・方向が維持され、街の検証を通る場合だけ住宅を追加する。街区の進行が異なるv1/v2は維持する。現在のセーブは読み込み時に22軒・4日目を確認した。
- 廃棄の金銭的なペナルティはなくすが、作り直しに使う時間と元の注文期限は残す。
- ピンの焼き上がりには、棚で判断待ちになった焼き上がり品も含む。配達できるかは注文カードの状態を確認する。
- 大きなクラスの全面改稿は行わず、既存ルールを維持する範囲で担当を整理した。
