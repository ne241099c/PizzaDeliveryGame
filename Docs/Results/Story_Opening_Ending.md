# オープニング・エンディング・ミッション達成の演出（Claude Code、2026-10-25）

人物は出さず、街・店・ピザ・数字だけで描く（ユーザー指示）。絵はすべてコードで組み立てる（新しい画像・シーン・プレハブの変更なし）。

## 営業終了時のミッション達成演出（`SettlementView.Missions.cs`）

- 「今日のまとめ」のレシートより先に、暗い背景の上へ「ミッション達成！」パネルが弾んで出る。
- その日のミッションが右から1件ずつ滑り込み、達成したものに順番に「達成！」の赤いハンコ。行が緑になり ☆→★、報酬が「+¥0 → +¥100」と数え上がる。未達成は灰色のまま。
- 最後のハンコの約1.3秒後に消えてレシートが始まる。どこかをクリック、または「次へ」「スキップ」で飛ばせる。
- 1件も達成していない日・倒産した日は出さない。

## オープニング（新しいゲームをタイトルから始めた時だけ）

1. 夜の街、窓に灯りがともる：「ある街のはずれに、小さなピザ屋が開きました。」
2. 夕方、ピザ屋（縞のひさし・「ピザ」の看板・窓のピザ）と配達の自転車：「窯も、配達の自転車も、借りたお金でそろえたものです。」
3. 借金のカードが ¥10,000 まで数え上がり、返す期限の札：「20日目の精算までに、ぜんぶ返しきろう。」（エンドレスは期限なし）
4. 夜明け、街が明るくなり「開店！」とピザが回る：「さあ、開店です！」

クリック（Space/Enter）で文字を全部表示→次の場面、「スキップ」（Esc）で終了。

## ローン完済時の選択

開店準備でローンを ¥0 にすると「ローン完済！」の確認が出る。

- 「20日目まで続ける」（エンドレスは「このまま続ける」）：そのまま経営。通常モードは20日目の精算のあと「エンディングへ ▶」でエンディング。
- 「エンディングへ ▶」：すぐエンディング。

## エンディング

1. 借金が ¥0 まで減り「完済」のハンコ。
2. 夜の街の屋根にピンが落ち、届けた枚数が数え上がる。
3. 店が大きくなり、店のグレードと★。累計売上。
4. 花火とピザが降り「おしまい」：「街は今日も、ピザを待っています。あそんでくれて、ありがとう！」

そのあと従来の「今回の成績」（エンドレスで続ける／タイトルへ）。準備中に選んだエンディングのあと「タイトルへ」を選ぶと、その回はエンドレスとして続きから遊べる。20日目にローンが残っていた場合はエンディングなしで従来どおり成績へ。
