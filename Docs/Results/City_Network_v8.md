# 道路網v8・道の太さ・道の編集・早送り（2026-10-24）

担当：Claude Code。shop、ローカルのみ、pushなし。

## 依頼と対応

| 依頼 | 対応 |
|---|---|
| 道をもう少し太く | 縮小しても道が画面上で8px（裏道・生活道路は約5px）より細くならない（`UITheme.mapRoadMinPixels`） |
| 交差点が少なすぎる | v8：新しい交差点から、近くの点へ最大2本の道を追加でつなぐ（`networkExtraLinks`）。地区ごとの交差点は6〜8個（`networkJunctionsPerDistrict`） |
| 家が行き止まりにしかない | v8：家は交差点どうしを結ぶ道の途中に建つ（その位置で道を2本に分ける）。分けるのはその地区で作った道だけなので、街が広がっても既存の道と家は変わらない |
| 道の編集の仕方がわからない | 伝票の入った配達員を選んでいる間、地図の道をクリックするとその道を通る（区間は回り道が一番短くなるものを自動で選ぶ）。もう一度クリックで元に戻す。マウスを乗せた道は黄色く光り、「クリック：この道を通る（◯◯）」と出る。「道を選ぶ」ボタンでの区間指定も残している |
| 押している間時間が加速するボタン | 「押している間 早送り」を、手順表示のあった場所に配置。押している間は実時間の4倍（`GameClock.fastForwardRate`）。離すと配達指示画面のゆっくり（0.1倍）に戻る |
| 「伝票を配達員のレーンへ」などの説明はいらない | 手順表示（①②）、注文一覧の「焼く前でも予約OK・下のレーンへ」、レーンの「伝票をここへドラッグ」「帰ってきたら、ここに入れられます」を削除。道の色の凡例は残した |

## 生成結果（5seed、最大14地区）

| 項目 | 値 |
|---|---|
| 家 | 100軒、すべて道の途中（2本以上の道に面する） |
| 交差点 | 97〜101個、うち3本以上の道が集まるもの65〜74個 |
| 行き止まりの交差点 | 7〜16個 |
| 街の幅 | 54〜60 |
| 生成時間 | 0.8〜1.0秒（全段階の検証を含む）、予備の街なし |

保存済みの街（v7以前）は、続きからの開店準備でv8に作り直される（資金・従業員・日数は維持）。

## 構成

- 画面の変更は `ShopUxUpgrade.ApplyDispatchControls` でBusinessView.prefabの該当部分だけを更新（手順表示と注文一覧の説明を削除し、早送りボタンと道の案内を追加）。元のプレハブは `Library/PrefabBackups/DispatchControls-20261024-033030`。
- 押している間の判定は `HoldButton`（新規、UI/Kit）。
- 道路網の検証 `CityGenerationValidation.RunNetwork` をv8の条件（家が道の途中、交差点の数）に更新し、Test Runnerに登録。
