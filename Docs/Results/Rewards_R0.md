# R-0 目標と報酬の影響調査

開始: shop / 23b712d。ユーザーが全体実装を承認。既存の計算・ルート探索は再利用する。

- CampaignManager.SettleDayは通常精算の直後に目標処理を追加できる。NextDayで通常20日結果への遷移を扱う。既存の営業・配達中の帰還待ちは共通。
- BusinessEconomyのLedger.Profitは維持。利息・返済・報酬は別の資金移動とし、精算後の所持金を表示する。
- CampaignSaveDataは開店準備のみ。目標状態を追加し、終了・返済結果を再起動で失わないため精算後の進捗を専用チェックポイントとして保存する必要がある。旧セーブは目標未導入として安全に初期化し既存の資金/従業員を維持。
- ProfileDataはcampaign.jsonと別のprofile.json。通常セーブの保存ロックを共用し、バックアップ・形式検証・復旧を行う。新ゲームでも消さない。
- 破産は現在も精算後の所持金で判定しInspectorの猶予設定がある。新仕様では目標モードで猶予なしにする。営業中の一時的な材料支払いから即中断せず、一日の精算で確定する。
- DayStatsに配達数/遅配/取消/★、Ledgerに売上/廃棄、CookingManagerに内勤生産枚数、DeliveryTripに3件持ち/裏道がある。追加統計は調理品質失敗・作成種類・訪問街区・手動経路と自動経路の予測差。
- FacilityManagerがピザ解禁と設備購入、MapManagerが日数拡張を管理する。既存購入・旧設備を維持し、グレード条件を解放資格として追加する。特別求人は確定除外なので通常求人を維持。
- 自動プレイはAssets/Editor/Simulation。既存測定は旧固定費/旧地図での早期破産が多く現行20日利益の根拠にはならない。R-7で同一seedの返済方針を測定し、初期ローンやスコア係数は仮値と明記する。

判断: 確定事項の利率0.5%/日を採用（旧本文の1%より優先）。R-6承認モックは未提供なので仮UIで全機能に到達できるようにし、正式な見た目はモック待ち。全検証の毎段階実行は現行AGENTSの関連検証方針を優先する。
