# 設備投資で稼げるようにする（Claude Code、2026-10-24）

## 調べたこと（変更前）

同じ街・注文で設備だけ変えて5日間の自動プレイ（[Facility_Value](Facility_Value/)。`Measurement_kitchen3.csv` は変更前・内勤3人、`Measurement.csv` は変更後・3つの街の合計）。

- 窯・作業台を増やしても売上は1円も変わらなかった。自動プレイの内勤は1人で、増やした窯・作業台を使う人がいない。内勤3人でも効果は小さく、維持費の分だけ赤字になることが多い。
- 自転車の速さアップは、配達件数をほとんど増やさなかった。
- 広告は注文を増やすが、さばき切れずにキャンセルが増え、費用分の赤字。
- メニュー拡張だけはピザ代が上がるので、確実に黒字。
- さらに設備はグレードで上限があり、20日間グレードが上がらないため、窯1台・自転車1段階までしか買えず、作業台は買えなかった。

## 変更

- **グレードによる設備の上限をなくした**：窯・自転車・作業台は1日目から最大Lv10まで買える（価格は従来どおり段階ごとに1.6倍）。街区とピザの解放はグレードのまま。
- **1段階ごとに売上が直接増える**（人手に関係なく効く）
  - 窯 +1台：ピザの売値 +8%（焼きたて）。注文の値段・メニュー表示にも反映。
  - 自転車 +1段階：速さ・事故率は従来どおり、さらに期限内の配達でピザ代の8%をチップとして受け取る。
  - 作業台 +1台：材料費 -20%（最低でも元の20%は払う）。
- **維持費を半分に**（窯37.5・自転車25・作業台18.75・メニュー12.5円/日）。
- 設備画面の説明を新しい効果に合わせた（いまの売値・材料費の倍率も表示）。メニューのピザ代表示を現在の金額に直した。
- 数値の置き場所：`EconomyScale`（`OvenSalesBonus`・`BikeTipBonus`・`WorkbenchMaterialSaving`・`MaintenanceFactor`）から Game シーンへ書き込み。

20日間の通し（seed 104、[Rewards_Equipment](Rewards_Equipment/README.md)）

| 方針 | 20日目の純資産 | スコア |
|---|---|---|
| 毎日できるだけ返済（投資しない） | 10455.96 | 18775.54 |
| 12日目まで設備投資（広告なし）→その後全額返済 | **12991.24** | **23373.22** |
| ずっと投資＋25%返済（広告も買う） | 4418.10 | 15437.30 |

投資してから返す方が、投資しないより純資産で約24%多い。最後まで買い続けると、終盤の高い設備が20日目までに元を取れない。

- 広告は今回変えていない（注文が増えてもさばけないと赤字）。
