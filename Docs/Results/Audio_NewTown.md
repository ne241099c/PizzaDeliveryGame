# 音とニュータウン型の街（Claude Code、2026-10-25）

## 音（`Assets/Scripts/Core/GameAudio.cs`）

- フリー素材（すべてCC0）を `Assets/Resources/Audio/` に置いた。出典と割り当ては [Credits_Audio.md](../Credits_Audio.md)。同じ名前のファイルに置き換えれば差し替えられる。
- BGM：タイトル・開店準備・精算は bgm_prep、営業中は bgm_business、オープニング・エンディングは bgm_story。
- 効果音：ボタン、注文が入った、つかむ／置く、伝票・具材・窯に入れる／出す、焼き上がりの帯に入った（1枚1回）、焼き失敗、箱詰め、ゴミ箱、出発、配達完了、遅れ・キャンセル、開店・閉店、ミッション達成のハンコ、返済・完済、ストーリーのページ送り。
- 調理の音はプレイヤーが手で行った操作だけ（`CookingManager.PlayerActed`）。内勤の作業では鳴らない。
- シーンに手を入れず、起動時に1つだけ作られるオブジェクトが各シーンのイベントを聞く。

## ニュータウン型の街（街の世代 v10、`CityGenerator.NewTown.cs`）

ユーザーの希望：道の密度を上げ、整理された街（たまプラーザ・美しが丘のようなニュータウン。碁盤ほどきっちりではない）。内部は変えず、見た目でカーブする道。

- **区画**：大きな街区（一辺5）をレンガ積みのようにずらして並べる。幹線は十字路ではなくT字路で出会う。店のまわりから1区画ずつ外へ育ち、前の日の道や家は動かない。
- **区画の中**：3つの型からひとつ。横に2本＋中央の縦1本／縦に2本＋中央の横1本／楕円のループ道。生活道路は少しふくらむ。各区画に斜めの裏道（土地勘）が1本。
- **ゆるいカーブ**：街全体をなめらかにゆがめ、向きも街ごとに回すので、長い通りが大きく曲がる。
- **見た目だけの曲線**：道のデータ（交差点・距離・経路計算）は直線のまま。`RoadGeometry` が交差点と家を通るなめらかな曲線（Catmull-Rom）で描き、配達員の移動・ルートの線・道のクリック・道沿いの建物もその曲線に沿う。
- **密度**：開始時（8区画）は交差点と家で約200点・道約255本・配達先58軒（v9より密）。行き止まりなし、すべての家に別ルートあり。
- **既存のセーブ**：続きから開くと、開店準備の段階で新しい街に作り直される（以前からある「古い街を更新する」設定のとおり。資金・従業員・日数はそのまま）。

検証：6つのseed×8/14区画で街の検証（つながり・行き止まり・近道・間隔・別ルート）がすべて1回目で合格。画面は [newtown](../UI_Screens/newtown/)。
