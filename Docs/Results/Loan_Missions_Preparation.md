# ローン返済とミッションを開店準備画面へ（Claude Code、2026-10-24）

## 変更

- **返済は開店準備の間だけ**（`RewardProgression.CanRepay`）。精算画面の「ローン返済・ミッション」ボタンと、≡メニューのミッション画面の返済操作は削除。
- **上のバーにローンの進み具合**（開店準備画面、常に表示）：ローン残り・返済％のバー・今日の利息・残り日数。押すと「ローン・ミッション」タブを開く。
- **左に5つ目のタブ「ローン・ミッション」**
  - 左：残り（大きく）・返済バー・返済済み/借りた額・利息と完済ボーナス・期限（残り3日以内は赤）・返済ボタン（1,000円／費用を残して返す／返せるだけ返す）・所持金と今日の費用の見込み。
  - 右：今日のミッション3件（☆挑戦中／★達成、報酬）と、通算の達成数・店のグレード。
- ≡メニューの「ミッション・ローン」は、開店準備中はこのタブへ移動。営業中は従来どおりの一覧（返済の案内のみ）。
- セーブ：借りた額 `rewards.borrowed` を追加（旧セーブは読み込み時のローン額）。返済と完済ボーナスは開店時の所持金も同額動かし、開店準備のセーブの整合（所持金＝開店時−準備費用）を保つ。

## 見つけて直した不具合

開店準備中に返済すると、セーブの整合チェックに引っかかり、「続きから」でセーブが読めなくなる状態だった（検証で発見、修正済み）。

## 検証

- RewardCampaign：準備中の返済・営業中/精算後は返済不可・返済後のセーブが読める・残り利息・完済ボーナス。
- RewardScreens：上のバーからタブを開く・ミッション3件・返済ボタンで1,000円返済・バーに10%表示・開店後は返済不可・メニュー画面に返済操作がない。
- 画面：[loan-missions](../UI_Screens/loan-missions/)。
