# チュートリアル S2-T（Claude Code、2026-10-24）

設計書（`Docs/Design/設計書_画面デザイン.md`）のとおり、タイトルから自分で選ぶ独立モード。本編の1日目には強制しない。

## 入口

- タイトルの「チュートリアル」を押せるようにした（初回起動の「はじめての人へ」の札は既存のまま）。
- 押すと章の選択：1. 作る ／ 2. 配達する ／ 3. 内勤と作り直し。
- `GameScenes.LoadTutorial(章)` → Game シーンを `LaunchMode.Tutorial` で開く。

## 進め方（`Assets/Scripts/UI/Tutorial/TutorialDirector*.cs`）

- 新しいゲームで店を開き、チュートリアル用の注文だけを出す（ランダムな注文は止める）。
- 案内カード（説明・手順の番号・「次へ」「やめる」）と、使う場所を囲む赤い枠（点滅）。カードは枠と重ならない隅に移動する。
- 実際にその操作をすると次の手順へ。説明だけの手順は「次へ」で進み、その間は時計が止まる。
- 営業時間を延ばして途中で閉店しない（チュートリアルを抜けると元の長さに戻す）。
- 終わると「次の章へ」「タイトルへ」。≡メニューを開いている間はカードを隠す。

| 章 | 内容 |
|---|---|
| 1. 作る（10手順） | 内勤なしで自分で調理。伝票→作業台、生地、ソース、チーズ、伝票の具、窯へ、緑の帯で取り出す、保温棚へ自動で箱詰め（失敗したら「そのまま出す」か作り直し） |
| 2. 配達する（7手順） | 焼き上がり2件。伝票をレーンへ、もう1枚も同じレーンでまとめる、道順の変え方、出発、早送りで2軒に配達 |
| 3. 内勤と作り直し（7手順） | 内勤が自動で作るのを見る。失敗ピザ（ソースが薄い・具がちがう）を焼いて保温棚へ、ゴミ箱で作り直し、8秒放置で内勤が引き継いで完成 |

## セーブ

チュートリアル中はセーブ・最高記録・プロフィール（トロフィー）を書かず、セーブを消すこともない（`AutomaticSavingEnabled=false`）。

## 検証

- Test Runner `Tutorial`：3章を最後まで、プレイヤーと同じ操作（調理API・レーン・出発ボタン・ゴミ箱）で進める。各手順が進むこと、営業時間が元に戻ること。
- 画面：`Tools/Review/capture_tutorial.py` で全手順を撮影し、枠が画面上の部品を見つけていることを確認（説明だけの手順以外はすべて1〜2個）。[tutorial](../UI_Screens/tutorial/)。
- タイトル：`TitleValidation` をチュートリアルボタンが押せる仕様に更新。

## 気づいた点
