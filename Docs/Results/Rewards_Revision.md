# 目標と報酬の修正（Claude Code、2026-10-24）

開始 a769198。ユーザーの追加依頼による修正。

## 変更

- **トロフィー**：称号「裏道の達人」をやめ、ミッション達成と節目のトロフィー10種（はじめてのミッション達成、ミッション10/30/60回、全達成の日、遅れゼロの日、まとめ名人、焦げなし10日、ローン完済、自分の目標を達成）。記録画面は★/☆と獲得数。図鑑（ピザ・街区・近道）の表示を削除。`profile.json` に `missionsCompleted` を追加（旧ファイルは0として読む）。
- **ミッション**：その日の3件は全部対象、選択操作なし。達成すると精算で自動受取。報酬は1件100円（グレードで増えない）。「遅れ・キャンセルなし」ミッションは候補から削除（`MissionKind.NoLate` は旧セーブの読み込み用に残す）。
- **お金**：ローン10000。費用×2.5、売上×3（`Assets/Editor/Builders/EconomyScale.cs` が Game シーンへ base×倍率で書き込む。再適用しても変わらない）。完済ボーナス250、ランク閾値・昇格の純資産×2.5、昇格の累計売上×3。
- **画面**：開店準備のヒント行を削除。営業中・準備中のローン/目標ボタンを削除し、精算画面にだけ「ローン返済・ミッション」。≡メニューに「ミッション・ローン」（営業中は開いている間時計が止まる）。
- **ゲームオーバー後の続きから**：R-1で外れていた「破産時にセーブ削除・設備リセット」を戻した。破産状態で保存済みのセーブは読み込み時に削除して新規開始、タイトルでは「セーブなし」扱い。最高記録・トロフィーは残る。
