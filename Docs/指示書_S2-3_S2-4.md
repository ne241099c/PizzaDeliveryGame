## S2-3 の指示文

調理の工程と品質を実装してください(`Docs/設計書_店内シーン.md` のS2-3)。`PizzaItem`(状態、品質の点、注文ID、見た目の層)と、工程の状態機械(生地 → ソース → チーズ → 具 → 焼く → 梱包)を作り、手動の操作を付けてください: 生地を材料棚から作業台へ、おたまで生地の上をなぞる(塗れた割合を測る。70%以上で1点)、チーズの容器のドロップ、具のトレイのドロップ(注文の指定の具なら1点)、ピザを窯へ(窯のゲージの帯の中で取り出すと1点。帯を過ぎて+5秒で焦げ=★1固定)、保温棚から箱へ、箱を閉じる(伝票が貼られる)。品質は点の合計(0点=★1、1〜2点=★2、3点=★3)で、得点ボーナスは★2が+15、★3が+40(期限内のみ。作り直しの損より大きくするため)、★3は評判+0.5です(いずれも調整可能)。精算に品質ボーナスの内訳を表示してください。作業台と窯は資源として扱い、使用中は他の注文で使えないようにしてください。伝票を作業台にドロップすると、その注文を自分で作り始められるようにしてください。M7の完璧ボーナス(+15)は、この品質ボーナスに置き換えてください(窯の帯=1点として吸収)。失敗の扱いは次のとおりです。焦げは★1固定のまま配達できます。梱包のとき、ピザの種類が伝票と合わなければ警告を出し、そのまま出しても客は受け取り(具の点なし)ます。焼き上がり・梱包の直後に、ミスしたピザの横に、ミスの内容と「このまま出す」「捨てて、作り直す」の2ボタンのふきだしを出してください(選ばなければそのまま台に残す)。ピザをゴミ箱(厨房の作業台の近く。置ける間は光る)にドラッグしても廃棄でき(右クリックかEscで取り消し)、廃棄には材料費(`wasteCost`、初期値20)がかかります。廃棄したら、同じ伝票に「作り直し」の札を付けてレールに残し、作業台に新しい生地を出してください(期限は進み続けます)。生焼け(帯の前に取り出した)は窯に戻して続きを焼けるようにしてください。廃棄した枚数と損失額を精算に表示してください(承認モックは `Docs/UI_Mock/Redo.png`)。期限が切れた注文のピザと箱は片付けてください。既存の全検証と、新しい検証(工程の遷移、品質の計算、焦げ、違う具、廃棄と作り直し、生焼けの戻し、資源の競合、期限切れ)が通ることを確認してください。

## S2-4 の指示文

内勤を実装してください(`Docs/設計書_店内シーン.md` のS2-4)。`KitchenStaff`(手際、丁寧さ。0〜1)を追加し、求人に内勤の候補を出し、雇用・解雇・日給(`40 + 50 × (手際 + 丁寧さ)`)・採用費・解雇手当を配達員と同じ仕組みで扱ってください。名簿の上限は配達員と合計です。開始時の名簿は、配達員2人(Aoi、Ren)に内勤1人(見習い、手際0.4・丁寧さ0.4)を加えてください。セーブ・ロードに含めてください。
内勤は、空いている作業台と窯で、伝票を取り、S2-3の工程の状態機械を自動で動かしてください。窯までの工程の時間は `時間 × (1.3 − 0.6 × 手際)`、各工程の成功は丁寧さで確率的に決め、窯の取り出しは自動(焦げない)にしてください。内勤が作ったピザが★1(0点)になったら、期限に余裕がある(残り時間 ≥ 作り直しの所要+配達の最短所要。`redoMinRemainingSec`)ときは、自動で廃棄して作り直してください(材料費は店の負担で、精算の廃棄に計上。作り直しの伝票は内勤の待ち行列の先頭=最優先に入れる。★2以上は作り直さない。閾値 `redoBelowStar` は初期値2で調整可能。プレイヤーがふきだしで「このまま出す」を選んだ伝票には働かない)。伝票は既定で内勤に自動で回り、プレイヤーが作業台にドロップした伝票は内勤が取らないようにしてください。作業台の増設(1→2→3台、費用400 / 700、維持費は1台につき+15/日)を設備に追加してください。店の画面のスタッフ・求人に、内勤のカードを(配達員と区別して)表示してください。乱数は固定して検証できるようにしてください。既存の全検証と、新しい検証(雇用・日給・上限・自動調理・割り当て・セーブ・★1の自動作り直しと優先順位・期限に余裕がないときはそのまま出す)が通ることを確認してください。
