# ピザ・生成マップの実装記録

2026-10-23 / shop / Codex。ユーザー添付の設計書をDocsへ反映。既存実装の差分から進める。通常セーブの保存抑制を使用、pushなし。

## 配達速度と窯のキュー

配達速度を1.2倍（所要時間は従来の約83.3%）にした。MapManagerのdeliverySpeedMultiplierで調整。閉店後の8倍速は維持する。
窯は全台共通の先着順キュー。満杯でも完成したピザを受け付け、作業台を空ける。空き次第自動で焼き始める。内勤のピザも同じキュー。手動ピザの取り出しタイミングの操作は維持する。窯ごとの固定予約にはせず、最初に空いた窯を使う判断。

関連検証312項目通過（新規8、M7 83、店内51、M3/M4 170）。旧仕様の「満杯の窯は拒否」をキュー受付に更新。通常保存抑制のまま新規→タイトルで終了。
